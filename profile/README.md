## About LODEXI

LODEXI is a high-performance, cost-effective AI platform designed to seamlessly integrate Retrieval-Augmented Generation (RAG) capabilities into your workflows. Whether you are building intelligent chatbots, analyzing internal documents, or connecting AI to WhatsApp, Telegram, and Google Apps Script, LODEXI provides the tools you need.

We believe that deploying AI should be simple, powerful, and accessible for modern startups.

---

## 🏗️ Our Architecture

LODEXI is built using a modern **Polyrepo** architecture, separating concerns into highly optimized services:

- **[lodexi/lodexi](https://github.com/lodexi/lodexi)**: The main enterprise dashboard and API gateway (built with Laravel 13 & React).
- **[lodexi/lodexi-core](https://github.com/lodexi/lodexi-core)**: The high-performance RAG and Vector AI engine (built with Python & FastAPI).
- **[lodexi/docs](https://github.com/lodexi/docs)**: The official markdown documentation for the ecosystem.

---

## 🌟 Key Capabilities

- **Bring Your Own Key (BYOK)**: Securely manage your own OpenAI or Anthropic API keys.
- **Instant Integrations**: Generate API tokens in seconds to connect with downstream apps.
- **Knowledge Management**: Upload and index your company's documents directly into our vector databases.
- **Real-Time Analytics**: Monitor your LLM token usage and latency in a beautiful dashboard.
